# assets

Shared assets used by Rig's tests and examples. Paths in scripts resolve through
`asset.path(...)`, so files here can be referenced relative to the calling script.

## Fonts

- `DejaVuSans.ttf` — DejaVu Sans (regular). A general-purpose UI/body face we can
  use for overlays, labels, and other interface text as well as display type.
  - Source: <https://dejavu-fonts.github.io/>
  - License: Bitstream Vera / DejaVu (permissive); see `DejaVuSans-LICENSE.txt`.
